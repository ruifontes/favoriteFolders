# Pastas e ficheiros favoritos

## Informações
* Autores: Rui Fontes, Ângelo Abrantes e Abel Passos Júnior, baseados no trabalho de Marcos Antonio de Oliveira e Chai Chaimee"
* Compatibilidade: NVDA 2022.1 e seguintes

## Apresentação
Regista as pastas e ficheiros mais utilizados pelo utilizador. 
Pode ser utilizado a partir de qualquer janela. 

Se for ativado a partir do Explorador de ficheiros, o botão "Adicionar" ficará disponível para adicionar a pasta ou ficheiro atual, caso não existam.
No processo de criação do registo, é sugerido o próprio nome da pasta ou ficheiro, mas este pode ser alterado.
Para abrir uma pasta ou ficheiro registado, basta que pressione enter sobre ele, ou ative o botão "abrir". 
O nome dado a uma pasta ou ficheiro pode ser alterado, para isso ative o botão "Renomear". 
Para excluir uma pasta ou ficheiro do registo, pressione Delete sobre ele ou acione o botão "Remover". 
Se o extra for ativado a partir de um campo de edição, o botão "Escrever no campo de edição" ficará disponível.
Ao ativá-lo, o cursor será movido para o início da linha e, em seguida, é inserido o caminho da pasta.
Isto é bem útil em janelas para guardar ou abrir ficheiros.

## Importante
 Algumas pastas, como Documentos ou Transferências, quando abertas através de atalhos, podem não mostrar na barra de endereço o caminho padrão.
Para as adicionar, é necessário abrí-las pressionando  enter sobre elas. 
A inserção do caminho não funciona em campos de edição como os documentos do Microsoft Word, Microsoft Outlook, etc, mas funciona apenas nas janelas de abrir e Guardar.

## Comando
WINDOWS+BACKSPACE - Abre a janela das pastas favoritas;
SHIFT+WINDOWS+BACKSPACE - Abre a janela dos ficheiros favoritos.
